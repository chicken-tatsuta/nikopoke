# カミシンカ周辺のレビュー

対象：前回追加したカミシンカ、関連する行動順・特性・AI・対戦再生。全技・全世代の本家完全一致を保証するレビューではない。

## 修正した問題と統合

- **はがねのせいしん**：相手の特性でも自分の鋼技が1.5倍になる不具合を修正。現在のシングル対戦では攻撃者自身の有効特性を判定する。前回追加した「相手のそうだいしょうと重なる」という誤ったテストも訂正した。
- **瀕死の特性発動**：HP0でも登場時フックを呼べた経路に生存判定を追加。瀕死のいかくがイベントを生成しないテストを追加。
- **行動順**：通常時と進化後で重複していた優先度・グラススライダー・トリックルーム・同速比較を `move_priority` / `sort_actions` に統合。乱数生成回数と既存の順序ルールは維持。
- **AI**：MCTS/Minimax/Vegaの進化候補を `append_move_variants` に統合。通常技・交代を維持し、イックンX/Yの候補と使用済み時の不追加を回帰テストで確認。
- **対戦演出**：例外で再生フラグ・オーバーレイが残り続ける経路を `finally` で解放。正式な解決済み盤面も反映し、途中表示が次の対戦状態として残ることを防止。

## 初回レビュー時の指摘（履歴）

以下は初回レビュー時点の記録。現在はユーザー指定で6項目を改善し、特性引き継ぎのみ独自仕様を維持した。最新の動作と検証結果は [改善報告](battle-alignment.md) を参照。

| 優先度・箇所 | 現在の挙動・影響 | 改善案 |
| --- | --- | --- |
| P1：両者の通常交代 / `battle.rs` | 交代の素早さを両者とも0として乱数順にする。登場時の天候などの最終状態が本家と異なり得る | 交代元の有効素早さで比較。技とは比較ルールを分け、同速・トリックルーム・天候の競合をテストする |
| P1：特性変更 / `events.rs` | `SetAbility` / `SwapAbilities` はIDとログを変えるが、新特性の開始処理を呼ばない。途中取得したそうだいしょうの記録不足、ひでりの未発動などが起こり得る | 特性の終了・変更・開始を共通化。進化・ガス復帰・スキルスワップで使う。登場専用効果の誤発動を避けるため、開始処理と登場時処理を分離する |
| P1：特性無視 / `effects.rs` | `ignore_ability` が対象の防御側特性だけでなく、自分の威力補正・てきおうりょくの一致補正も止める。一部の特性無視技が弱くなる | 攻撃者/防御者の無視対象と、無視できる特性のフラグを分けて検証する |
| P2：睡眠 / `statuses.rs` | 保存された残りターンより `elapsed` の判定を優先。2回目に1/3で起床、3回目に必ず起床。保存カウンターを期待する既存テストも失敗している | 付与時にターンを決定し、行動時に減算する方式に統合。はやおき・ねむる・交代を別ケースで確認する |
| P2：ダメージ丸め / `effects.rs` | 中間値を浮動小数で扱い最後に切り捨てる。あついしぼうも攻撃実数値ではなく威力を半分にしている。端数が出る条件で本家と差が生じ得る | 準拠世代を固定し、能力補正・基礎ダメージ・最終補正ごとの整数丸めと既知の本家計算例を導入する |
| P2：どくしゅ / `abilities.rs` | 接触・みがわり・毒の型無効は確認するが、りんぷん・おんみつマントによる阻止がない | 追加効果を防ぐ有効特性・持ち物の共通判定を作る。現在の通常種族/持ち物データに該当項目はないが、追加時に必要 |
| 要ルール確認：レシーバー/かがくのちから | 登場した個体が、自分のパーティで直前に倒れた個体の特性をコピーする。本家のダブルで味方が倒れた際の発動とは異なる | 本家準拠なら味方瀕死イベントへ移す。現シングル対戦向けの既存独自ルールの可能性が高いため、勝手に無効化しない |

カミダマの共通化・複数所持・進化時のHP維持・独自EV上限32/合計66は既存/依頼仕様として維持した。

## 検証結果

- Rust：224件成功、3件失敗。失敗は前回も確認済みの睡眠・技データ検査の3件で、追加の失敗なし。
- カミシンカ専用16件成功。今回追加した瀕死特性・共通AI候補の回帰テストを含む。
- WASM再ビルド、実WASM/JSONの送受信相当・重複要求・リセット検証、456技/24種族のデータ検査成功。
- TypeScript・Vite本番ビルド、ブラウザーでの予約/解除・操作ロック・交代/再登場・スマートフォン幅を検証。

主な変更ファイル：`core/battle.rs`、`core/abilities.rs`、`core/kamishinka.rs`、`ai/{mcts,minimax,vega}.rs`、`tests/{abilities,kamishinka}.rs`、`BattlePage.tsx`、配信用WASM、実装/レビューメモ。
